# Store each corpus as JSONL with Markdown views

Each generated corpus uses one complete document aggregate per JSONL line and one title-based Markdown view per record. JSONL preserves document, text-highlight, note, tag, Reader open-time, and available content structure for `jq` and regular-expression queries, while Markdown keeps the same material readable and searchable in Obsidian. Documents with no content are reported and retained as metadata-only records. Reader highlight rows with no text are reported and omitted because their selected content cannot be represented without guessing. Both forms are generated because a Markdown-only corpus loses structure and a JSONL-only corpus is awkward to read.
